GitHub Readme Stats

A self-hosted suite of GitHub profile README cards (activity graph, stats, streak, top languages, trophy) rendered as SVG images, ready to embed in a profile README. No auth, no tracking, cached at the edge.

Usage:

/graph?username=xsrazy&theme=tokyo-night&days=31

Parameters: username (GitHub username), theme (100 themes, for example tokyo-night, github-dark, dracula, nord, rose-pine), days (7 to 365, default 31).

New: the theme builder composes fully custom card URLs visually, with live preview and copy buttons. Every card also accepts bg_color (hex or gradient), title_color, text_color, border_color, hide_border, border_radius, custom_title, and hide_title.

More cards

The same API also renders four companion cards, all sharing the username and theme parameters:

Stats card — total stars, forks, contributions (last year), PRs, issues, followers, and public repos:

/stats?username=xsrazy&theme=tokyo-night

Streak card — total contributions, current streak, and longest streak:

/streak?username=xsrazy&theme=tokyo-night

Languages card — top languages by bytes across the user's repos. Layouts: layout=normal|compact|donut, plus langs_count and exclude_lang:

/languages?username=xsrazy&theme=tokyo-night

Trophy card — achievement trophies with ranks (UNKNOWN, C, B, A, AA, AAA, S, SS, SSS) for stars, followers, contributions, pull requests, issues, public repos, and account age. All trophies always render together in a single row:

/trophy?username=xsrazy&theme=tokyo-night

Customization examples

Custom colors on the stats card (title_color, text_color, bg_color, border_color):

/stats?username=xsrazy&title_color=ff6e96&text_color=f8f8f2&bg_color=282a36&border_color=ff79c6

Gradient background (bg_color=30,e96443,904e95):

/stats?username=xsrazy&bg_color=30,e96443,904e95

Languages donut layout (layout=donut, langs_count=8):

/languages?username=xsrazy&layout=donut&langs_count=8

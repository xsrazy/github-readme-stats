Activity Graph API

A self-hosted GitHub contribution activity graph that renders as an SVG image, ready to embed in a profile README. No auth, no tracking, cached at the edge.

Usage:

/graph?username=xsrazy&theme=tokyo-night&days=31

Parameters: username (GitHub username), theme (tokyo-night, github-dark, react, radical, highcontrast), days (7 to 90, default 31).

More cards

The same API also renders three companion cards, all sharing the username and theme parameters:

Stats card — total stars, forks, contributions (last year), PRs, issues, followers, and public repos:

/stats?username=xsrazy&theme=tokyo-night

Streak card — total contributions, current streak, and longest streak:

/streak?username=xsrazy&theme=tokyo-night

Languages card — top languages by bytes across the user's repos:

/languages?username=xsrazy&theme=tokyo-night
